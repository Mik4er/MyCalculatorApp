# Practical Work No. 1 | AOP (Aspect-Oriented Programming)

## Project Overview
A simple graphical calculator built with **C#** and **Windows Forms**. This is the first practical assignment for the "Aspect-Oriented Programming" course, focusing on basic UI interactions and arithmetic logic.

## Features
*   **Arithmetic Operations**: Addition, subtraction, multiplication, and division.
*   **User Interface**: Custom-styled buttons and layout for better usability.
*   **Dynamic Results**: Results are calculated and displayed instantly upon clicking the button.
*   **Operation Selection**: A dropdown menu to choose between different mathematical operators.

## Technologies
*   **Language**: C#
*   **Framework**: .NET (Windows Forms)
*   **IDE**: Visual Studio 2022

## How to Run
1. Download the repository as a ZIP or clone it.
2. Open `CalculatorApp.slnx` in Visual Studio.
3. Press `F5` to build and run.
